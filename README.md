## 📜 Что тут лежит

| Папка                    | Содержимое                                                                                                                     |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------ |
| `src/leetcode/`          | ~30 решённых задач — от TwoSum и FizzBuzz до GenerateParentheses и буквосочетаний с кнопочного телефона                        |
| `src/codewars/`          | ~28 ката: Pig Latin, шашечный конь (BFS), Scramblies, SumOfK и т.д.                                                            |
| `src/algos/`             | Классика: бинарный поиск, пузырёк, QuickSort, шифр Цезаря, XOR                                                                 |
| `src/datastructures/`    | Свои LinkedList, Stack и Queue написаны руками, без `java.util` - чтобы понять, как оно устроено внутри                        |
| `src/multithreading/`    | Первые попытки в многополочку, `MyThread1..4`                                                                                  |
| `src/olympic/`           | Олимпиадные задачи из разных турниров (папки `old`, `newolympic`, `ifogot`, `ffebruary`)                                       |
| `src/recursion/`         | Рекурсии. Лёгкие задачи. Смотреть снизу вверх, осторожно ⚠️                                                                    |
| `src/OOP/`               | Первые классы, наследование                                                                                                    |
| `src/randDatePrototype/` | **⚡ Прототип будущего [Randate](https://github.com/pavlent1yy/Randate)** — консольная зародышевая версия. Отсюда всё началось |
| `src/bimage/`            | Эксперименты с BufferedImage и картинкой `image.png` 🖼️                                                                        |
